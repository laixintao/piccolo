## Fixes from validation

1. `latest` detection split the reference at the registry port's colon. It now
   checks the tag suffix of the repository name, including IPv6 registries.
2. The reverse proxy rejected valid `206 Partial Content` responses. Range
   responses now pass through and count as mirror hits.
3. A failed peer immediately committed `502` before another peer was tried.
   Failed attempts now leave the response untouched until a peer succeeds or
   all peers miss.
4. Code inspection after the deletion assertion found that missing blob
   metadata was mapped to `500`. Missing content now returns `404` and an INFO
   upload miss. A blob deleted between size lookup and opening also clears the
   obsolete Content-Length. This final change has local regression coverage;
   VM verification remains pending because of the suspension below.
5. A local race-suite run exposed process-wide containerd ingest-lock collisions
   between parallel fixtures. Fixture ingest references now include each
   temporary store path.
